# Books to save by hand in Firefox: the sites need a click, a form or "Print to PDF", so no script can fetch them.
# The app lists them under Library -> Get books -> Save by hand (with Open in Firefox and a tick box).
# Format, one item per line (the note is the rest of the line):
#   M|<folder>|<title>|<web page>|<how: button | print-to-pdf | form | zip>|<note>
# button       = the page has a download button (Download a PDF, Download PDF ...)
# print-to-pdf = the book is a web page: Firefox menu -> Print -> Save to PDF (older Firefox: Print to File, PDF)
# form         = the site asks for a name or e-mail address before the download
# zip          = a zip file: unpack it into the folder
# Keep it in step with the "Manual downloads" sections of kit/0-README-start-here.md (a test checks the addresses).
